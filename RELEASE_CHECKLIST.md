# Release checks

Current release: v3.3.

- Publish the core skill, supporting references, schemas, scripts and tests.
- Keep client workspaces, original developer decks, caches and generated private reports out of the package.
- Run package unit tests and skill format validation before publishing.
- Review the staged diff and preserve the existing license and previously published examples.
- Default final deliverables are Markdown and same-content DOCX; enforce body-length, visuals/data, review revision and export checks.
- Historical website examples remain illustrative and are not newly certified against v3.3 gates.

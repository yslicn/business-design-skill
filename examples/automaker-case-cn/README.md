# 某汽车公司业务设计案例 — 中文

使用现代浏览器[直接查看在线中文报告](https://yslicn.github.io/business-design-skill/report-cn.html)。

## 样例生成方式

1. Business Design skill 生成并校验底层 `business_design.json`，再确定性生成 `business_design.md`。
2. Claude Cowork 基于该 Markdown 制作本中文版咨询报告 HTML。

HTML 不是 Business Design skill 的原生输出，而是非正式的下游沟通呈现层。本演示型公开案例不分发源 JSON 和 Markdown。

## 声明

本案例对目标公司使用化名，分析来自公开信息研究，仅用于展示 skill 的业务设计能力。由于部分公开市场事实具有辨识度，案例原型仍可能被推断，因此它属于“基于公开信息的化名案例”，而不是不可逆匿名数据。文件不包含客户工作区、保密源文件、个人路径或源文件指纹。本报告不代表相关企业、Claude Cowork 或 Anthropic 的认可，也不构成投资建议或对企业当前状况的声明。
